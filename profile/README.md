# WPShipReady

**Deliver WordPress sites with proof, not promises.** WPShipReady is a toolkit for Claude Code that takes a client site from the brief to a verified launch report, from the makers of [DocxToWP](https://docxtowp.com).

| | |
|---|---|
| **Toolkit** | Requirements the client signs off, a plugin stack that's been tested, a custom block theme, a QA report where every result comes from a test that ran, and a handover pack. |
| **SEO Kit** | A page-by-page SEO audit of any WordPress site, with fixes for Yoast SEO or Rank Math that you approve, check on the page, and can undo. Nothing installed on the site. |
| **Check engine** | The open-source engine behind the [free WordPress launch check](https://docxtowp.com/free-tools/wordpress-launch-check): [wpshipready-kit/wpshipready](https://github.com/wpshipready-kit/wpshipready) (MIT). |
